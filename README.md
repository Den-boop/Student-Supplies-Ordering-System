# Student Supplies Ordering System

## Project Description

The Student Supplies Ordering System is a simple browser-based application developed using HTML, CSS, and JavaScript. It allows customers to select school supplies, manage their shopping cart, calculate their total purchase, and complete cash payments.

## Features

- Displays six school supplies with their prices.
- Allows customers to add products to the shopping cart.
- Supports increasing and decreasing product quantities.
- Allows customers to remove products from the cart.
- Automatically calculates subtotals and the overall total.
- Validates cash payment amounts.
- Calculates the customer's change.
- Generates a digital receipt with transaction details.
- Allows a new transaction after successful payment.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select products and add them to the shopping cart.
5. Enter the cash payment and confirm the transaction.
6. View the digital receipt or start a new transaction.
